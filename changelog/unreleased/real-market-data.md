EXBO approved the site's API application, so the auction pages now show the
actual market instead of the demo fixture. Price history is real sales, and the
chart says so — anything not coming from the live API is still labelled, so a
number you see is either the market or plainly marked as not.

You can also sign in with your EXBO account now, which is what saving and
upvoting builds has been waiting on.
